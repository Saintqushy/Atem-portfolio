LOCAL DEVELOPMENT

1. Activate the Python virtual environment.

Windows PowerShell:

    .\venv\Scripts\Activate.ps1

2. Make sure the required environment variables exist in:

    .env

3. Install dependencies if necessary:

    pip install -r requirements.txt

4. Run the application:

    python app.py

5. Open:

    http://127.0.0.1:5000


ADMIN LOGIN

Open:

    http://127.0.0.1:5000/admin/login


CREATE OR UPDATE ADMIN ACCOUNT

With the virtual environment activated:

    flask --app app create-admin

Enter the administrator username and a strong password when prompted.

Passwords are stored as password hashes in PostgreSQL.


DATABASE

The application uses Neon PostgreSQL.

The PostgreSQL connection string is supplied using the:

    DATABASE_URL

environment variable.

Database tables include:

- admin_users
- messages
- projects
- certificates
- site_settings


FILE STORAGE

Uploaded files are stored using Supabase Storage.

This includes:

- Project images
- Certificate preview images
- Certificate PDF documents
- CV PDF files

The PostgreSQL database stores references to these files rather than
storing the files themselves.


REQUIRED ENVIRONMENT VARIABLES

Production environment variables must be configured on the hosting
platform and must NEVER be committed to GitHub.

Examples include:

    DATABASE_URL
    SECRET_KEY
    SUPABASE_URL
    SUPABASE_SECRET_KEY
    SUPABASE_BUCKET
    COOKIE_SECURE
    FORCE_HTTPS
    FLASK_ENV


SECURITY

- Never commit the .env file.
- Never commit database passwords.
- Never commit Supabase secret keys.
- Never hard-code production credentials inside app.py.
- Use a long random SECRET_KEY in production.
- Use HTTPS in production.
- Set COOKIE_SECURE=true when running over HTTPS.
- Keep dependencies updated.
- Keep administrator credentials private.


GIT

Files such as the following should remain excluded through .gitignore:

    .env
    venv/
    .venv/
    __pycache__/
    *.pyc
    portfolio.db
    app_sqlite_backup.py

The old SQLite database is no longer the production database.
