# Atem Manyok — Portfolio

My personal portfolio site. Built with Flask on the backend, PostgreSQL for data, and Supabase for file storage. Deployed on Vercel.

## Stack

- Backend: Python, Flask
- Database: PostgreSQL (Neon)
- File storage: Supabase
- Frontend: HTML, CSS, JavaScript
- Hosting: Vercel
